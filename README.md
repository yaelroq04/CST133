## Course Overview

CST 133 introduces the design and implementation of sequential digital logic circuits, with an emphasis on Verilog HDL and programmable logic devices.

Throughout the course, students explore techniques for designing, simulating, and implementing digital circuits using both software tools and physical FPGA hardware.

Topics covered include:

- Boolean logic and digital circuit review
- Programmable logic devices and FPGA design
- Verilog HDL and structural, dataflow, and behavioral modeling
- Latches and flip-flops
- Registers, counters, and clock dividers
- Timing analysis and signal generation
- Finite State Machines (FSMs)
- Moore and Mealy state machines
- Simulation and verification using testbenches
- Arithmetic Logic Units (ALUs)
